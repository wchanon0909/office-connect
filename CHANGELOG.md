# Changelog

## v1.0 — Repository organization

- Grouped frontend code by responsibility; moved styles and default layout files into dedicated directories.
- Updated entry-point paths without changing script order, cache query strings or application code.
- Preserved the existing domain, backend configuration, assets and default layout.
- Replaced the long README with a project overview; archived the original release notes verbatim.
- No new SQL or feature changes.

## v1.0 — Personalization & Friendship

Expanded avatar options, outfits, tutorial, friendship EXP, achievements, optional quests and shop catalog.

- Hall-zone hotfix: reserved temporary conversation zones and arrival-gated chat (SQL 41 in historical notes).
- Login and chat dock hotfix: guest Login button, hidden member launchers and aligned speech dock.
